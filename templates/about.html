About Eventify

Eventify is an Event Discovery & Management System designed to make finding and joining events simple and convenient.

🎉

What is Eventify?

Eventify is a web-based platform where users can discover upcoming events, view event details and register for events.

🚀

Our Features

• Discover upcoming events

• View event details

• Register for events

• User login and registration

• Event calendar

💻

Technology Used

Eventify is developed using HTML, CSS, Python Flask and SQLite database.

🌟

Our Goal

Our goal is to provide a simple platform that helps users discover, explore and participate in different events.
